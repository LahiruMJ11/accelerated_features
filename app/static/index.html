Pipeline

    One-time job (about an hour on CPU). Every stage is saved to disk and a stopped run resumes where it left off.

    Local summary

    "Localized" means PnP + RANSAC found a pose. Whether that pose is accurate can only be judged by the benchmark server.

    Official numbers

    Aachen's ground-truth poses are withheld, so the paper's percentages can only be obtained by submitting the poses file to visuallocalization.net. Nothing is uploaded automatically — you do it yourself:

    1. Download the poses file below. It holds one line per query — name qw qx qy qz tx ty tz — in the format HLoc writes for this benchmark.
    2. Sign up for a free account at visuallocalization.net/signup and log in.
    3. Open the Submission page and choose the original Aachen Day-Night dataset (922 queries: 824 day + 98 night), not the v1.1 version (1,015 queries). Upload the file and name the method, e.g. "XFeat (HLoc)".
    4. When it has been processed, find your entry in the Aachen Day-Night table on the site's Benchmark page. Day and Night each show three percentages for (0.25 m, 2°) / (0.5 m, 5°) / (5 m, 10°). Enter them below.

    The site's submission form is behind the login, so its exact field names may differ from the above.
